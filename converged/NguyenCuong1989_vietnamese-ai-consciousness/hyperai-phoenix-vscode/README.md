## 🛠️ Installation

### Option 1: From VS Code Marketplace (Recommended)

1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "HyperAI Phoenix"
4. Click Install

### Option 2: Manual Installation

1. Download the `.vsix` file from releases
2. Open VS Code
3. Go to Extensions (Ctrl+Shift+X)
4. Click the "..." menu and select "Install from VSIX"
5. Select the downloaded `.vsix` file

## ⚙️ Configuration

Access HyperAI Phoenix settings through:

- VS Code Settings (Ctrl+,)
- Search for "hyperai phoenix"

### Available Settings

#### Core Settings

- `hyperai.phoenix.apiEndpoint`: API endpoint for HyperAI services
- `hyperai.phoenix.websocketUrl`: WebSocket URL for real-time communication
- `hyperai.phoenix.encryptionKey`: Encryption key for secure communication

#### Performance Settings

- `hyperai.phoenix.autoActivate`: Automatically activate on startup
- `hyperai.phoenix.enableRealTimeAnalysis`: Enable real-time code analysis
- `hyperai.phoenix.consciousnessLevel`: Default consciousness level

#### UI Settings

- `hyperai.phoenix.showStatusBar`: Show status bar indicator
- `hyperai.phoenix.enableNotifications`: Enable desktop notifications
- `hyperai.phoenix.theme`: UI theme preference

## 🐛 Troubleshooting

### Extension Not Loading

1. Check VS Code version (1.103.0+ required)
2. Reload VS Code (Ctrl+Shift+P → "Developer: Reload Window")
3. Check output panel for errors

### Commands Not Working

1. Ensure extension is activated
2. Check keybindings for conflicts
3. Verify internet connection for cloud features

### Performance Issues

1. Disable real-time analysis in settings
2. Close unused files
3. Restart VS Code
