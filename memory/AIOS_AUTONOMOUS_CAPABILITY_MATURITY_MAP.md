# AIOS Autonomous Capability Maturity Map

Date: 2026-04-18

## Purpose

This map turns the ecosystem from a flat set of surfaces into a maturity-graded operating fabric.

Capability alone is not authority. Each surface must be evaluated by runtime class, authority class, proof source, gate condition, and current mission-role readiness.

## Maturity Levels

- `L0 observed_only`
- `L1 classified_surface`
- `L2 governed_worker_candidate`
- `L3 proof_producing_executor`
- `L4 route_open_execution_adapter`
- `L5 mission_root_capable`

## Required Fields Per Surface

Each maturity entry should include:

- runtime class
- authority class
- current maturity
- proof source
- gate condition
- allowed mission roles
- blocked roles
