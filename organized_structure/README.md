## 🔍 Cách Sử Dung / How to Use

### Tìm File Nhanh / Quick File Search

```bash
# Tìm file AI engine
find organized_structure/02_AI_ENGINES -name "*.py"

# Tìm file test
find organized_structure/08_TESTING -name "*test*.py"

# Tìm tài liệu
find organized_structure/07_DOCUMENTATION -name "*.md"
```

### Thêm File Mới / Adding New Files

1. Xác định nhóm phù hợp dựa trên chức năng
2. Đặt file vào thư mục con tương ứng
3. Cập nhật README nếu cần

### Duy Trì Tổ Chức / Maintenance

- Chạy script `auto_file_organizer.py` định kỳ
- Kiểm tra file mới trong `01_CORE_SYSTEM/01_Core_Files`
- Di chuyển file vào thư mục chuyên biệt khi cần

## 📝 Quy Ước Đặt Tên / Naming Conventions

### Thư Mục / Directories

- Số thứ tự + tên tiếng Anh: `01_Core_Files`
- Không dùng khoảng trắng: `Development_Tools`
- Dùng dấu gạch dưới: `Natural_Language_Processing`

### File / Files

- Tên mô tả chức năng: `quantum_consciousness_engine.py`
- Thêm hậu tố version nếu cần: `system_v2.py`
- Sử dụng lowercase và underscore: `file_organizer.py`
