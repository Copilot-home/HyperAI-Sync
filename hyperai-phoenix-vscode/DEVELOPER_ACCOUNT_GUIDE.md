# Microsoft Developer Account Setup Guide

## Prerequisites

1. Microsoft Account (Outlook.com, Hotmail, or Microsoft Account)
2. Valid payment method for publisher verification
3. Business email address (recommended)

## Steps to Create Publisher Profile

### 1. Access Partner Center

1. Go to https://partner.microsoft.com/
2. Sign in with your Microsoft Account
3. Navigate to "Visual Studio Marketplace" → "Publish extensions"

### 2. Create Publisher Profile

1. Click "Create publisher profile"
2. Choose a unique publisher name (e.g., 'hyperai')
3. Provide publisher display name
4. Add contact information
5. Agree to terms and conditions

### 3. Verify Account

1. Add payment method for identity verification
2. Complete publisher profile information
3. Wait for account verification (usually 24-48 hours)

### 4. Prepare Extension for Submission

1. Ensure package.json has correct publisher name
2. Build extension (.vsix file)
3. Test extension locally
4. Prepare screenshots and descriptions

### 5. Submit Extension

1. Go to Partner Center → Visual Studio Marketplace
2. Click "New extension"
3. Upload .vsix file
4. Fill in extension details
5. Submit for review

## Important Notes

- Publisher name cannot be changed once set
- Keep payment method active for annual renewal
- Response time for submissions: 7-10 business days
- Free extensions don't require payment method after initial setup
