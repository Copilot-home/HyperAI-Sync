Welcome to your standard workspace structure! This environment has been initialized and optimized to integrate seamlessly with your agentic tools and modern development setup.

## Directory Structure

- 📂 **`projects/`** — Place your active web apps, backends, and full-stack services here.
- 📂 **`scripts/`** — A hub for your automation workflows, server checkups, and Python utilities.
- 📂 **`experiments/`** — Run rapid prototyping, research sandboxes, and API playground tests.
- 📂 **`styles/`** — Contains the central design system and globally accessible styling.
- 📂 **`src/`** — Houses logic and modules for your personal Developer Cockpit.

---

## 🛠️ The Developer Cockpit

The cockpit is a local dev dashboard powered by **Vite** that serves as your development cockpit. It provides interactive widgets, real-time diagnostic checks, copy-to-clipboard developer shortcuts, and visual navigation panels.

### Running the Dashboard Locally

To start the dashboard dev server:

```bash
# 1. Install Vite dependency
npm install

# 2. Boot up the Vite hot-reloading dev server
npm run dev
```

The app will compile instantly and automatically launch in your browser at `http://localhost:3000`.
